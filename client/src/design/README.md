# NOVA Design System

## Personality
**Editorial + Minimal + Premium + Social + Human + Confident**

## Core Rules
1. **No AI Tropes**: No purple/blue gradients, no floating background blobs, no excessive glassmorphism, no card-in-card nesting.
2. **Typography First**: Single typeface — **Plus Jakarta Sans** — used across the entire product. Hierarchy is achieved through size, weight, and line-height, not loud colors.
3. **Warm Neutral Palette**: Warm editorial background (`#FAFAF8` light / `#0D0D0D` dark) with a signature coral accent (`#FF5C35` light / `#FF6845` dark) used selectively.
4. **Restrained Radius System**:
   - Small controls: `8px`
   - Buttons & Inputs: `9–10px` (Never giant capsules)
   - Cards: `12–14px`
   - Large Surfaces: `16px`
   - Pills: Only when semantically appropriate (e.g. unread count badges)
5. **Hairline Borders over Heavy Shadows**: Continuous timeline streams divided by subtle hairline borders (`border-b`).
6. **Lucide React Icons Only**: Standard 18–20px stroke, strictly purposeful, never decorative.
7. **Responsive Shell**: Dedicated 240px navigation rail, optional right rail (never forced on Messages, Calls, or Settings), and minimum ~44px mobile touch targets.
